# Earth textures

| File | Used for |
|---|---|
| `2k_earth_daymap.jpg` | Day side of the globe |
| `2k_earth_nightmap.jpg` | City lights on the night side |

Both are 2048×1024 equirectangular maps (longitude 0 at the image centre). The filenames match
[Solar System Scope's texture set](https://www.solarsystemscope.com/textures/), which is licensed
CC BY 4.0. Confirm that is where these came from and keep the attribution if you redistribute them.
